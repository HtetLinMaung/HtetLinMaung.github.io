## Design Context

### Users
Visitors evaluating Htet Lin Maung for portfolio, freelance, or hiring opportunities. They need a fast overview of capabilities, selected work, credibility signals, and contact paths from a single landing page.

### Brand Personality
Professional, precise, approachable. The interface should feel polished, trustworthy, and quietly confident rather than experimental.

### Aesthetic Direction
Reference-led portfolio design based on the original portfolio mockup. Light theme, airy spacing, soft shadows, blue accent color, editorial hero scale, and clean product-card presentation. Match the composition as closely as possible while replacing the hero image and icon set with original local assets/CSS treatments.

### Design Principles
1. Preserve the reference layout, hierarchy, and pacing with minimal interpretation.
2. Keep the presentation crisp and professional through restrained color and shadow use.
3. Use original SVG/CSS visuals where the mockup uses photos or icon packs.
4. Prioritize scanability: strong headings, compact supporting text, clear CTAs.
5. Maintain responsive behavior without changing the essential desktop composition.
